# 离线掌上工作台

保留网址分组、添加/删除、待办完成状态、便签自动保存、深浅主题及 PWA 离线缓存。所有初始列表为空。

## 运行与验证

任意静态文件服务器即可。Python 3：

```sh
python3 serve.py
```

打开 `http://127.0.0.1:8080`。首次加载后可离线使用。浏览器数据由用户保管，源码不带 localStorage 快照。

## 拆分边界

已删除天气、RSS 代理、远程图标、搜索引擎、个人默认站点和原 App 图标；只在用户点击自己添加的网址时离开当前页面。不含 iOS 签名工程，交付为可跨平台运行的 PWA。

初始数据均为合成样例。运行后用户输入/导出属于用户自己的数据，不能随源码发布。源码采用 MIT 许可证，见 LICENSE；本目录没有携带原仓库历史。

浏览器回归（需先按上文启动服务）：`npm install --ignore-scripts`，`npx playwright install chromium`，然后设置 `TEST_URL` 为该服务地址并运行 `npm run test:browser`。浏览器使用独立无窗口上下文，截图写入 `work/`，不读取现有浏览器资料。

## 2026-11-08 协作修订

- 切换页面前先提交编辑草稿，离开页面时也尝试保存。
- 存储失败会保留未保存草稿并明确提示，不以旧存储内容伪装已保存。
- Docker默认仅发布127.0.0.1，扩大绑定需显式BIND_ADDRESS。

集合根目录 `verify_release.py --project external-pocket-workbench` 可复跑测试和包内首次使用示例；Web实际交互的浏览器证据另记。原版本测试数是历史记录，本轮以集合验证报告为准。


### 多页面编辑与保存

请使用支持 Web Locks 的新版浏览器，通过 README 的本机服务打开。一个页面持有编辑权直到关闭或刷新；其他页面可以查看，写入会明确拒绝并保留待办/便签输入。关闭原编辑页后，返回另一页重试保存。未保存便签不会被后续跨页通知覆盖；离页先同步保存便签再释放编辑权。浏览器不支持安全互斥时不写入，避免整库覆盖。
